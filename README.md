# BabajagaBoB

GUI-first foundation for an autonomous full-stack agent platform.

## First milestone
- Active Control Center shell
- Agent Observatory
- Mission queue
- Execution queue with lease/retry/cancellation states
- Experiment status
- Live activity events
- Emergency lockdown state
- Network-deny/privacy indicators
- Explicit progress and execution states

## Run
npm install
npm run typecheck
npm run build
npm run dev
